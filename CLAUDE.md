### What is ropagen?

[ropagen](https://ropagen.eu) is an LLM-powered tool (University of Ulm, DBIS institute) that helps users create GDPR Records of Processing Activities (ROPA) documents — the Article 30 compliance records organisations must maintain. It uses a Mistral LLM and offers three interaction modes:

| Mode | Description |
|------|-------------|
| **Form** | Structured questionnaire — checkboxes and fields, minimal LLM interaction |
| **Ask** | Guided dialogue — LLM explains each section interactively |
| **Chat** | Freeform conversation — user describes their processing, LLM generates the ROPA |

The central problem ropagen addresses: *creating ROPA documents is tedious, time-consuming, and requires legal expertise most organisations lack.*

### Research questions

**RQ1 — User experience:** How do varying levels of LLM support affect usability, efficiency, and cognitive load? Which mode do users prefer and feel most confident with?

**RQ2 — Document quality & confidence gap:** How does document quality differ across modes when generated by novices? Is there a gap between perceived confidence and actual output quality?

### Study design

- **N = 73** university students (novices — no prior GDPR knowledge)
- **Within-subjects** experiment: every participant used all three modes
- **Counterbalanced** order via Latin Square (6 groups) to control for learning effects
- **~90 minutes** per session; single standardised GDPR scenario (university data processing)
- **Instruments:** SUS (System Usability Scale), NASA R-TLX (cognitive load), 7-point Likert confidence questions, mode preference rankings, completion time

### Evaluation pipeline

NLP metrics comparing AI-generated ROPA documents against a single expert-created reference:

| Metric | What it captures |
|--------|-----------------|
| BLEU | N-gram precision with brevity penalty |
| ROUGE-1/2/L | Unigram / bigram / LCS overlap (F1) |
| METEOR | Precision–recall balance with synonym matching |
| BERTScore P/R/F1 | Token-level semantic similarity (ModernBERT) |
| SBERT Similarity | Document-level cosine similarity (sentence embeddings) |

Results: 219 documents (73 participants × 3 modes). Typical ranges: BERTScore F1 ~0.88–0.92, SBERT ~0.98–0.99, BLEU ~0.05–0.24.
